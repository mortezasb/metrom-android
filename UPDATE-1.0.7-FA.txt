Metrom Android — Source Revision 1.0.7
======================================

این بسته فقط Source Revision پروژه Android است. اولین انتشار فروشگاه همچنان:
versionCode = 1
versionName = 1.0.0

تغییرات اصلی:
- Splash برند اصلی حفظ شده و سطح بعدی به Loading واقعی بدون لوگوی تکراری تبدیل شده است.
- برای Providerهای سازگار TWA، تصویر محلی Loading به Splash مرورگر منتقل می شود.
- اجرای آفلاین فقط بعد از حداقل یک تایید موفق Digital Asset Links روی همان نصب و همان Browser Provider مجاز است.
- اگر کاربر برای بار اول آفلاین باشد یا Browser Provider عوض شده باشد، برنامه داخل UI Native می ماند و هیچ Browser fallback با URL باز نمی کند.
- موتور BackgroundMetronomeService دست نخورده و مستقل از HTTP/Polling/Database باقی مانده است.
- ACCESS_NETWORK_STATE فقط برای تشخیص محلی اتصال Validation شده استفاده می شود.

برای Build نهایی، سورس را در GitHub جایگزین کنید و همان GitHub Action امضاشده پروژه را اجرا کنید.
